# Security Policy

## Supported versions

MissionBraid is currently a source-candidate project. Security fixes are applied to the latest code
on the default branch; no production-support commitment or private advisory SLA is claimed yet.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose credentials, private workspace
content, or enable unintended command execution. Contact the repository owner privately through the
owner's GitHub profile contact channel and include the affected version, reproduction steps, impact,
and any suggested mitigation. Remove secrets and personal data from the report.

The maintainer will confirm receipt when possible and will coordinate disclosure after a fix is
available. This policy does not authorize testing systems or accounts you do not own or control.
