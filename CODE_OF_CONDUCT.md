# Code of Conduct

MissionBraid contributors are expected to keep project spaces respectful, constructive, and free
from harassment. Discuss ideas and implementation evidence rather than attacking people, respect
different backgrounds and levels of experience, and avoid publishing private information.

Project maintainers may edit or remove harmful contributions and may restrict participation when
these expectations are repeatedly or seriously violated. Report conduct concerns privately through
the repository owner's GitHub profile contact channel; do not open a public issue containing private
or sensitive details.
